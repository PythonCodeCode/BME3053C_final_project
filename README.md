# BME3053C_final_project
This is a repository for the BME3053C Final Project. Additional detail can be seen on the Read Me.

# Instructions for Use.
Download the datafile and notebook.
Create a google drive folder named "project_final_bme".
Place the datafile and notebook inside that folder.
Open the notebook using Collab and run the two code blocks in order.

# About the project
This project uses a dataset with ECG features already extracted.
